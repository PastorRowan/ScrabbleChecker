
# ScrabbleChecker

A cross-platform Tauri application that checks whether a word is valid in Scrabble.

## Features

- Cross-platform desktop application
- Checks whether a word is a valid Scrabble word
- Fast word lookup
- Rust backend
- Tauri application framework

## Getting Started

### 1. Clone the Repository
```
git clone https://github.com/PastorRowan/ScrabbleChecker.git
```

### 2. Set Up the Scrabble Dictionaries

ScrabbleChecker loads its Scrabble dictionaries from the following directory:
```
src-tauri/resources/dictionaries
```

Additional Scrabble dictionaries can be added. See the [dictionary setup guide](src-tauri/resources/dictionaries/README.md) for more info.

### 3. Traverse to the project directory
```
cd ScrabbleChecker
```

### 4. Install Dependencies
```
npm install
```
### 5. Build frontend
```
npm run build
```

### 6. Run the Application
```
npm run tauri-dev
```
This command will also build the rust backend before running the application.

## How It Works

The application accepts a word from the user and checks it against the application's Scrabble dictionary.

The Rust backend is responsible for the word-validation logic and dictionary handling, while the frontend provides the user interface.

### Windows x86_64

> [!NOTE]
> The Windows build must be performed on a Windows development environment.

The following components are required:

- [Microsoft C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)
- MSVC toolchain
- Windows Rust target: `x86_64-pc-windows-msvc`

Verify that the Windows MSVC Rust target is installed:
```
npm run installed-target-list
```

The following target is required for the Windows build:
```
x86_64-pc-windows-msvc
```

If it is not installed, add it with:
```
rustup target add x86_64-pc-windows-msvc
```

Build the Windows application:
```
npm run tauri-windows-build
```

Tauri will build the Rust application in debug mode and generate the configured Windows application bundles/installers.

### Android aarch64

Android builds require:

- [Android Studio](https://developer.android.com/studio)
- Android SDK
- Android NDK 25
- Android SDK Command-line Tools
- Java 25
- Android Rust target: `aarch64-linux-android`

Verify that the Android Rust target is installed:
```
npm run installed-target-list
```

If it is not installed, add it with:
```
rustup target add aarch64-linux-android
```

Make sure the `ANDROID_HOME` environment variable points to your Android SDK installation directory.

For example, on Windows:
```
ANDROID_HOME=C:\Users\user_name\AppData\Local\Android\Sdk
```

Initialize the Tauri Android project:
```
npm run tauri-android-build-init
```

Build the Android debug APK:
```
npm run tauri-android-build-debug
```

The resulting APK will be generated in the Tauri Android build output directory.
